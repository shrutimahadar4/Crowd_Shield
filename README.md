**CrowdShield – AI-Based Crowd Management and Stampede Prediction System**

CrowdShield is an AI-powered system designed to monitor crowd density in real time using CCTV footage, video uploads, and live camera feeds. It uses YOLOv8 for people detection and provides crowd density heatmaps, real-time people counts, risk-level indicators, and emergency alerts to help identify potential overcrowding and reduce the risk of stampedes.

**Key Features:**
- Real-time crowd detection and monitoring
- Green, yellow, and red crowd density heatmaps
- Crowd count visualization and analytics
- Risk indication and emergency notifications
- Support for CCTV, camera feeds, videos, and images
- Incident logging and monitoring dashboard

**Tech Stack:** Python, Streamlit, YOLOv8, OpenCV, SORT Tracker, SQLite, Twilio SMS

CrowdShield aims to make public spaces safer through intelligent crowd monitoring and early risk identification.
